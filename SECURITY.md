# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately by emailing
[dev@cybertkr.com](mailto:dev@cybertkr.com). Do not open a public issue for a
suspected vulnerability.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within 72 hours.

Never include access tokens, refresh tokens, session files, private keys,
passwords, phone numbers, verification codes, proxy credentials, or other
account secrets. Revoke and rotate any credential that may have been exposed.

## Supported versions

Security fixes are provided for the latest published pre-release or release.
Older revisions may be unsupported.
